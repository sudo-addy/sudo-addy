# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| Latest  | ✅ Yes             |
| Older   | ❌ No              |

## Reporting a Vulnerability

I take security seriously. If you discover a vulnerability in any of my projects, please report it responsibly.

### How to Report

1. **Do NOT** create a public issue
2. Email me at **abhijitrdohe@gmail.com** with:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

### What to Expect

- **Acknowledgment** within 48 hours
- **Assessment** within 7 days
- **Fix** deployed as soon as possible after verification
- Credit given in the fix commit (unless you prefer anonymity)

### Scope

This policy applies to all public repositories under [sudo-addy](https://github.com/sudo-addy).

### Out of Scope

- Vulnerabilities in third-party dependencies (report to the upstream project)
- Issues in forked repositories that exist in the original

## Best Practices

All projects aim to follow security best practices:

- Dependencies are kept up to date
- Secrets are never committed to repositories
- Input validation is applied where applicable
- HTTPS is enforced for all web-facing projects

Thank you for helping keep these projects secure.
